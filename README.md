# Data analysis - Formula 1 2024 - Dashboard

Authors: Alexis Burnier-Framboret, Tristan Clowez, Corentin Delaporte

This project is a data analysis of the Formula 1 2024 season, with the aim of creating a dashboard to visualize the data. The data is collected from the [Kaggle](https://www.kaggle.com/) website.

The dashboard is created using Dash and Plotly, and is hosted on a personal VPS.

You can access the dashboard [here](https://dash.torisutan.fr).
